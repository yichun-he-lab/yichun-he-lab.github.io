# He Lab Website

A modern, responsive lab website inspired by the Wang Xiao Lab design, showcasing computational biology and AI research.

## Features

- **Responsive Design**: Mobile-friendly layout that adapts to all screen sizes
- **Modern Styling**: Clean, professional design with smooth animations
- **Interactive Navigation**: Smooth scrolling with active section highlighting
- **Research Showcase**: Dedicated sections for research areas, publications, and team members
- **News & Updates**: Latest lab news and achievements
- **Contact Information**: Easy access to lab contact details and location

## Sections

### Home
- Hero section with lab introduction
- Research focus overview
- Institutional affiliations (Broad Institute, MIT, Harvard)

### Research
- **Spatial Biology**: Mapping cell types and molecular profiles in spatial context
- **AI for Scientific Discovery**: Developing autonomous AI systems for research
- **Multi-modal Data Integration**: Combining diverse biological data types
- **Computational Neuroscience**: Understanding neural circuits through computation

### Publications
- Recent high-impact publications
- Links to papers, code, and data
- Publications in Nature, Cell, Nature Communications, etc.

### People
- Principal Investigator profile (Yichun He)
- Lab member cards with photos and contact information
- "Join Us" section for recruitment

### News
- Latest lab updates and achievements
- Publication announcements
- Conference presentations

### Contact
- Lab address and contact information
- Interactive map placeholder
- Email and social media links

## Technical Details

### Built With
- **HTML5**: Semantic markup for accessibility
- **CSS3**: Modern styling with Flexbox and Grid
- **JavaScript**: Interactive features and smooth animations
- **Google Fonts**: Inter font family for clean typography

### Key Features
- Fixed navigation header with smooth scrolling
- Intersection Observer API for scroll-based animations
- Responsive grid layouts
- CSS transitions and hover effects
- Mobile-first responsive design

## Customization

### Content Updates
- Update personal information in the People section
- Add actual publication details and links
- Replace placeholder news items with real updates
- Update research descriptions to match specific focus areas

### Styling Customization
- Modify colors in `styles.css` (primary color: #2c3e50, accent: #667eea)
- Adjust fonts by changing the Google Fonts import
- Update spacing and layout by modifying CSS Grid and Flexbox properties

### Adding New Sections
1. Add new HTML section with unique ID
2. Update navigation menu in header
3. Add corresponding CSS styling
4. Update JavaScript for smooth scrolling

## Deployment

### Local Development
1. Open `index.html` in a web browser
2. Use a local server for best results (e.g., `python -m http.server`)

### Web Deployment
- Compatible with GitHub Pages, Netlify, Vercel
- No build process required - static HTML/CSS/JS
- Simply upload files to web hosting service
